01知识库放在哪里

选一个空文件夹或新文件夹，程序会在里面自动创建「01未处理 / 02已处理 / 03知识提炼 / 04知识聚合 / 05规则模板」等标准结构。填好后点「保存位置」，再点「创建知识库」即可一键生成；也可直接点「打开该路径」在文件管理器里查看或新建。

02未处理资料（01未处理，整理前可随时删减）

把资料放进「01未处理」后，用下方「豆包自动整理」批量提炼成标准笔记并自动建立知识链接。

04高级设置

开启后，豆包整理将跳过链接引擎 / 处理报告；点「复位」可撤销调试期间的全部操作：删除新建的笔记/日志，并把已处理素材移回 01未处理。调试期请用网页「豆包自动整理」，勿用命令行 sync（会污染既有笔记的相关笔记区块）。
